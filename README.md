# Mentoria para o Sucesso

Portal institucional inicial em Next.js 15, React e TypeScript.

## Execução

```bash
npm install
npm run dev
```

## Situação

Esta versão contém apenas o portal público, sem autenticação, banco de dados ou área do aluno. Os cursos estão identificados como **em preparação**. Não publicar chaves ou credenciais no repositório.
